# Welcome to the OASA drive

This is OASA's shared drive for members. Anything you put here, every member can see and change.

## Folders

| Folder | What goes in it |
|---|---|
| **00 Start Here** | These guides. Kept up to date from the `joinoasa/share` repo, so edits here get replaced. |
| **Projects** | One folder per project or tech tree node, named by its ID: `T-DOCK2 Docking station`. |
| **Hardware** | CAD, datasheets, wiring diagrams, test results. |
| **Media** | Photos, video, renders, event pictures. |
| **Events** | Meetups, demos, build days. |
| **Agents** | Where AI agents write their output. Check it before you use it. |
| **Inbox** | Not sure where something goes? Drop it here and say so in Discord. |

## Rules

- **No secrets:** no passwords, keys or tokens. Use 1Password.
- **No personal data** about applicants or members.
- **Name files clearly:** `2026-10-28 T-DOCK2 dock test.mp4`, not `IMG_4411.mp4`.
- **Code goes in GitHub. Writing you edit together goes in Google Drive.** This drive is for big files and finished work.
