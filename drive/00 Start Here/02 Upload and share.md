# Upload and share

## Upload

1. Open the folder you want.
2. Drag files onto the page, or click **Upload**.
3. Large files (videos, CAD) upload in parts. Leave the tab open until it finishes.

## Share with a member

Send them the drive address and the folder path, like `share.joinoasa.org`, then *Projects → T-DOCK2*. They sign in with GitHub and see it.

## Share with someone outside OASA

Right-click a file → **Share File**. Share links only work for signed-in OASA members right now. To send a file to someone outside OASA, ask an admin in Discord.

## Deleted something by mistake?

There's no recycle bin, but there is a nightly backup. Ask an admin in Discord with the file name and roughly when it was last there. Files saved before last night's backup can be restored.
