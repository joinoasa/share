# Your setup and first work

The full guides are on the website. Start here:

1. **Setup checklist:** https://joinoasa.org/docs/setup-checklist/ (tick it off with your buddy in week one)
2. **How work gets done:** https://joinoasa.org/docs/how-work-gets-done/ (pick, say so, do it in the open, get a review, close it)
3. **Don't write code?** https://joinoasa.org/docs/start-without-code/
4. **Guiding someone new?** https://joinoasa.org/docs/buddy-guide/

## Where your files go in this drive

Work on a tech tree node or project goes in `Projects/<node ID> <name>/`, for example `Projects/T-DOCK2 Docking station/`. Post the folder path on the node's GitHub issue so others can find it.
